# 폐기된 개별 카드 데이터

카드를 **종류 단위로만** 구분하도록 바꾸면서 걷어낸 개별 카드 정의다.
이름과 값어치를 하나하나 갖고 있었지만, 지금 시스템은 보상/중립/저주/파편
네 종류(저주는 파멸·부패·침식)만 알면 되므로 필요가 없어졌다.

카드 이름과 효과는 새로 설계할 예정이고, 그때 참고하려고 남겨 둔다.
지금 쓰는 정의는 `src/choice/balance.ts`의 `CARD_POOL`이다.

## 걷어낸 것

`cards.ts`에 옛 `CARD_POOL`과 `STARTING_DECK`을 그대로 옮겨 두었다.
보상 8종(은빛 검·강철 방패·룬 창·화염병·사슬갑옷·매의 눈·축복의 잔·오래된
성물), 중립 5종(낡은 단검·나무 방패·부싯돌·여행자의 외투·주머니칼), 저주 3종,
파편 1종이었다.

`value`는 "가장 값나가는 것을 버린다" 같은 선택지가 무엇을 집을지 정하는
값이었다. 종류마다 카드가 하나뿐인 지금은 종류별 상수와 같다.
