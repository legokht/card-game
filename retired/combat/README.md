# 폐기된 전투 프로토타입

여기 있는 것은 **더 이상 게임에 연결되어 있지 않다.** `tsconfig.json`의
`include`가 `src`와 `tests`만 보므로 타입 체크와 빌드에서도 빠진다.
나중에 참고할 수 있도록 남겨 둔 것이다.

## 무엇이었나

레인·웨이브 전투를 실험한 별개 프로토타입이다. 웨이브가 시작되면 **총 전력
숫자 하나만 공개**되고, 그것이 3개 레인에 어떻게 쪼개질지는 배치를 확정한
뒤에야 밝혀진다. 플레이어는 총량만 보고 추론하고 베팅한다.

- `index.html` / `src/main.ts` / `src/style.css` — 페이지와 진입점
- `src/engine/wave.ts` — 총 전력 분배 (패턴 선택 + 반응 강도)
- `src/engine/combat.ts` — 전투 규칙 (DOM 의존 없음)
- `src/engine/types.ts` — 전투 타입
- `src/data/balance.ts` — 곡선, 패턴 가중치, 반응 강도
- `src/data/cards.ts` — 플레이어 카드 정의
- `src/ui/render.ts` — DOM 렌더링
- `combat.test.ts` / `wave.test.ts` — 테스트

자동 플레이 400판 기준 승률 61%였다.

## 왜 폐기했나

본선은 2지선다(`choice.html`)이고 전투는 거기에 연결된 적이 없다. 손패 5장을
뽑아 싸우는 전투를 붙여 본 적이 있지만, 카드를 쓰고 소모하는 구조가 "뽑은
카드가 필드에 계속 쌓인다"는 지금 규칙과 맞지 않아 걷어냈다.

## 되살릴 때

`../../src/engine/rng.ts`를 가리키던 import 경로가 옮기면서 어긋났다.
지금 이대로는 컴파일되지 않는다 — 읽기 위한 기록이지 그대로 되살려 쓰는
코드가 아니다.
